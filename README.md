# Best-Looking Food Picture — make.fun food-picture-01

A dramatic close-up food photograph of a double smash burger: molten cheddar
dripping down two crispy patties, a glossy toasted sesame brioche bun, fresh
lettuce and tomato on dark slate, warm golden side light, a wisp of steam.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png` in the grader).

## The picture

- `entry.png` — 1024x683 PNG, 983,529 bytes (gate limit: 1 MiB, 1024x1024).
- One clear focal point, filling the frame: appetite first, then texture,
  styling and light — the judge's rubric.
